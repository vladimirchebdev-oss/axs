# Чтение по ТЗ: AXS + Cloudflare + браузер

Читать по порядку. Docker здесь нет.

Цель: понять, почему обычный Playwright падает на галочке Cloudflare и на запросе геолокации, и чем это закрывают NoDriver / CloakBrowser.

---

## 1. Почему появляется галочка Cloudflare

Turnstile сначала молча собирает сигналы браузера. Checkbox показывают только если сессия уже «подозрительная». Кликать галочку почти бесполезно, если fingerprint красный.

Обычный Playwright почти всегда красный: `navigator.webdriver`, следы CDP, headless, датацентровый IP, timezone не совпадает с прокси.

Поэтому в ТЗ стоят NoDriver или CloakBrowser, а не чистый Playwright. Внешние решатели капчи (2captcha, CapMonster и т.п.) запрещены.

Ссылки:

- Как работает Turnstile  
  https://developers.cloudflare.com/turnstile/

- Режимы виджета (managed / checkbox)  
  https://developers.cloudflare.com/turnstile/concepts/widget/

- Turnstile vs Challenge Page  
  https://developers.cloudflare.com/cloudflare-challenges/challenge-types/turnstile/

- Разбор сигналов (не инструкция по обходу)  
  https://blog.crawlex.net/blog/cloudflare-turnstile-internals/

## 2. Инструменты из ТЗ — выбрать один

### Если уже знаешь Playwright → CloakBrowser

Тот же API Playwright, меняется запуск браузера. Свой пропатченный Chromium.

- GitHub / README  
  https://github.com/CloakHQ/CloakBrowser

- Сайт  
  https://cloakbrowser.dev/

- PyPI  
  https://pypi.org/project/cloakbrowser/

В README смотри `proxy=...` и `geoip=True`: timezone и locale подтягиваются под IP прокси. Это прямо про геолокацию.

Нюанс: в ТЗ просят Chrome v152. У CloakBrowser свой Chromium (часто около v150). Версию надо сверить с формулировкой задания.

### Если без Playwright → NoDriver

Python-библиотека, наследник undetected-chromedriver. Управляет обычным Chrome через CDP, без Selenium и chromedriver. Chrome можно поставить именно v152.

  https://ultrafunkamsterdam-nodriver.mintlify.app/introduction

- GitHub

## 3. Геолокация — то, на чём обычно ломается Playwright

Нужны две вещи сразу, и обе до перехода на страницу:

1. Разрешение `geolocation` для origin сайта
2. Конкретные координаты, согласованные с IP прокси

NY-прокси + координаты Москвы = ещё один красный флаг.

Origin должен быть точным. Часто это `https://shop.axs.com`, а не `https://axs.com`. Если страница в iframe — origin у iframe может быть другим.

Нативный диалог «Разрешить доступ к местоположению» сам не нажмётся. Его лучше не показывать: permission выдаётся через API контекста, а не кликом по окну.

Ссылки (API тот же, если берёшь CloakBrowser):

- grantPermissions / setGeolocation  
  https://playwright.dev/docs/api/class-browsercontext

- Почему permission «выдал, а промпт всё равно есть»  
  https://qaskills.sh/blog/playwright-browser-context-permissions-geolocation

- Частая ошибка: выставил после навигации  
  https://webcrawlerapi.com/glossary/playwright/how-to-fix-playwright-geolocation-permissions

## 4. Anti-detect: Canvas, WebGL, AudioContext, User-Agent

Это не магические флаги, а конкретные сигналы, по которым сайт отличает бота от человека.

Ссылки:

- 6 техник fingerprinting  
  https://fingerprint.com/blog/browser-fingerprinting-techniques/

- Canvas / WebGL / Audio  
  https://browser.lol/en/blog/canvas-webgl-audio-the-fingerprints-that-survive

- FingerprintJS (как ориентир, что собирают сайты)  
  https://github.com/fingerprintjs/fingerprintjs

Проверить, что торчит в обычном Chrome и в своём скрипте:

- https://www.browserscan.net/
- https://abrahamjuliot.github.io/creepjs/

Смысл: увидеть разницу, а не «скопировать обход».

## 5. Прокси

ТЗ: HTTP, HTTPS, SOCKS5. Задаются через конфиг или env. Переключение без рестарта сервиса. Проверка прокси до использования.

Важно:

- Один процесс Chrome = один прокси. Это ограничение Chrome.
- Ротация: новый browser context или новый браузер на новый прокси.
- Chrome через `--proxy-server` плохо ест `user:pass`.
  - NoDriver: `create_context(proxy_server=...)`
  - CloakBrowser: аргумент `proxy=`
- Timezone, locale и геолокация должны совпадать с IP прокси.
- Датацентровый IP часто сразу ловит Cloudflare, даже с хорошим браузером. Для теста заказчик обещал выдать прокси.

## 6. Что уже выяснилось про AXS простым HTTP

Обычный GET без браузера:

- HTTP 403
- `Server: cloudflare`, cookie `__cf_bm`
- тело не пустое (~452 KB HTML)
- title: AXS, без билетов и без кнопки корзины

Магазин так не открыть. Нужен живой браузер.
