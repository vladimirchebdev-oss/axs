# 🕷️ Python Developer (Web Scraping)

Разработайте мини-сервис на Python с использованием NoDriver или CloakBrowser для автоматизированного взаимодействия с сайтом билетов [AXS.com](http://axs.com/)

> ⚠️ Сервис должен обходить **защиту Cloudflare** и **поддерживать использование прокси**

> 🐳 Сервис должен быть полностью контейнеризован и запускаться через **Docker**

## 📍 Минимальные требования

1. Использовать **Chrome v152**
2. Использовать **NoDriver** или **CloakBrowser** для автоматизации браузера
3. Поддерживать **настраиваемые** и **ротационные прокси**
4. Успешно обходить **Cloudflare** (Turnstile/captcha)
5. После загрузки защищённой страницы либо **сделать скриншот**, либо **добавить билет в корзину**
6. Предоставить **полную настройку Docker** **(dockerfile + docker-compose**), чтобы проект запускался в контейнерах от начала до конца

## ⚙️ Функциональные требования

### 🅿️ Основной функционал

1. Открыть конкретную страницу события на [AXS.com](http://axs.com/) (https://shop.axs.com/?c=axs&e=6414022407626854 , https://shop.axs.com/?c=axs&e=4436620017755968)
2. Автоматически пройти защиту Cloudflare без использования каких-либо внешних
сервисов решения captcha
3. После успешной загрузки страницы выполнить одно из следующих действий (сохранить
скриншот страницы / добавить билет в корзину)
4. Сохранить итоговый результат (скриншот и/или логи)

### 🌐 Работа с прокси

1. Должен работать с HTTP, HTTPS и SOCKS5 прокси
2. Прокси можно задавать через config-файл или переменные окружения
3. Сервис должен позволять переключать прокси без перезапуска
4. Прокси должны проверяться и валидироваться перед использованием

> ℹ️Мы предоставим прокси для этого тестового задания. Если возникнут какие-либо проблемы, пожалуйста, сообщите нам

### 🎭 Требования anti-detect

1. Скрыть любые признаки автоматизации (webdriver flags, значения navigator и т.д.)
2. Рандомизировать User-Agent
3. Использовать правдоподобный browser fingerprint
4. Корректно обрабатывать cookies и localStorage
5. Имитировать поведение человека (небольшие случайные задержки, движение мыши, прокрутка)
6. Подменять fingerprints WebGL, Canvas и AudioContext

### 🐳 Требования Docker

1. Использовать production-ready Dockerfile
2. Включить docker-compose.yml для простого запуска
3. Подключать volumes для скриншотов и логов
4. Позволять конфигурацию через переменные окружения
5. Держать образ лёгким (предпочтителен multi-stage build)

### ❌ Ограничения

**Нельзя** использовать любые внешние сервисы, которые решают captcha за вас

Это значит **никаких** **инструментов** вроде **2captcha**, **Anti-Captcha**, **DeathByCaptcha**, **CapMonster** или любых других платных/бесплатных captcha solvers

### ⚠️ Помните!

Обход Cloudflare должен быть реализован исключительно через:

1. Техники автоматизации браузера
2. Anti-detect механизмы
3. Подмену browser fingerprint
4. Эмуляцию реалистичного поведения браузера
5. Тайминг и человекоподобные взаимодействия
